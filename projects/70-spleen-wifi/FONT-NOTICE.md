# Spleen font notice

This project contains selected bitmap data generated from Spleen 2.2.0 by
Frederic Cambus. The upstream BDF files are included unchanged in
`fonts/upstream/` and are pinned to upstream Git commit
`57f9219328c9f5873085320fe8bc8f7dd34b8791`.

Spleen is distributed under the BSD 2-Clause License. The complete upstream
license is available at `fonts/upstream/LICENSE`.

The tram and other pictograms in `src/main.cpp` are original project artwork;
they are not part of Spleen.
