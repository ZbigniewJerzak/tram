# Font and icon notice

`src/MesloFontData.h` contains a modified, monochrome bitmap subset generated
from `MesloLGS NF Regular.ttf`, version 1.210 / Nerd Fonts 2.3.3. The exact
source file used for generation had this SHA-256 digest:

```text
d97946186e97f8d7c0139e8983abf40a1d2d086924f2c5dbf1c29bd8f2c6e57d
```

The subset contains printable ASCII, seven German glyphs, and five Font
Awesome-compatible Nerd Font symbols. The full TTF is not copied into this
project.

review the upstream license texts before public distribution.
